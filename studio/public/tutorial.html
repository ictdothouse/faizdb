Module 1: 60-Second First Launch & 5-Way Universal Gateway

Module 2: Multi-Dialect Duality (Insert Mongo -> Query SQL)

Store documents with MongoDB syntax and query them instantly with Relational SQL.

Scenario: Frontend developers love working with flexible JSON documents (MongoDB style), while data analysts and backend reporting teams need standard SQL queries. FaizDB unifies both without ETL pipelines! 
// Inside faizdb shell or MongoDB Compass (Port 27017):
db.inventory.insert({
  "sku": "GPU-5090",
  "name": "NVIDIA RTX 5090",
  "category": "Hardware",
  "price": 1999.00,
  "stock": 42
});
-- Query the EXACT SAME collection using relational SQL:
SELECT name, price, stock 
FROM inventory 
WHERE category = 'Hardware' AND price > 1000 
ORDER BY price DESC;
from pymongo import MongoClient

# Connect directly using official PyMongo driver on port 27017:
client = MongoClient("mongodb://127.0.0.1:27017")
db = client["faizdb"]
db.inventory.insert_one({"sku": "GPU-5090", "price": 1999.00, "stock": 42})
print("Inserted successfully into unified LSM storage!")

Module 3: E-Commerce & Ticketing (Zero Oversell ACID MVCC)

Guarantee zero overselling during high-concurrency ticket and flash sale checkouts.

Scenario: 5,000 concert fans click "Buy Ticket" at the exact same millisecond when only 2 tickets remain. Under standard NoSQL, race conditions cause overselling. FaizDB enforces Multi-Version Concurrency Control (MVCC) with Write-Ahead Log (WAL) safety. 
# 1. Begin Atomic Snapshot Transaction
curl -X POST http://127.0.0.1:27018/v1/transaction/begin \
  -H "Authorization: Bearer "

# 2. Deduct Seat Inventory (Condition: available_seats > 0)
curl -X POST http://127.0.0.1:27018/v1/collections/tickets/update \
  -d '{"query": {"concert": "Coldplay-KL", "seats": {"$gt": 0}}, "update": {"$inc": {"seats": -1}}}'

# 3. Commit atomically (If conflict occurs, transaction aborts cleanly)
curl -X POST http://127.0.0.1:27018/v1/transaction/commit
-- Interactive Shell / psql:
BEGIN TRANSACTION;
UPDATE tickets SET seats = seats - 1 WHERE concert = 'Coldplay-KL' AND seats > 0;
INSERT INTO orders VALUES (101, 'Faiz', 'Coldplay-KL', 350.00, 'PAID');
COMMIT;

Module 4: AI Vector Embeddings & Semantic Search (HNSW)

Sub-millisecond Approximate Nearest Neighbor (ANN) search inside your database.

Scenario: You're building an AI Chatbot or Semantic Document Search. Instead of paying for a separate Pinecone or Milvus cluster, FaizDB indexes up to 4,096-dimension vectors natively using SIMD-accelerated HNSW. 
# Inside faizdb shell:
demo vector

# Output will index 4 concept vectors and perform sub-millisecond similarity search!
# Ingest vector embedding into 'knowledge_base' collection:
curl -X POST http://127.0.0.1:27018/v1/vector/search \
  -H "Content-Type: application/json" \
  -d '{
    "collection": "articles",
    "query_vector": [0.92, 0.88, 0.08, 0.06],
    "top_k": 3,
    "metric": "Cosine"
  }'
import fetch from 'node-fetch';

const res = await fetch('http://localhost:27018/v1/vector/search', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    collection: 'faq',
    query_vector: [0.15, 0.82, 0.33, 0.91],
    top_k: 2
  })
});
const matches = await res.json();
console.log('Top match similarity:', matches[0].similarity);
