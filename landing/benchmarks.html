🔬 Scientific Workload Methodology & I/O Scope:
• Hot In-Memory Working Sets (< 1 ms): Sub-millisecond figures reflect warm/hot working sets residing in memory (MemTable SkipList, resident HNSW layers, and ARC block cache) evaluated via Criterion and loopback TCP streams.
• Cold Storage NVMe Physics: For cold datasets exceeding physical RAM, random read latency is governed by physical NVMe/SSD hardware bounds (10–50 µs per page fetch), with read amplification minimized via Bloom filters and two-level block indexing.
