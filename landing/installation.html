Deployment Guide

Installation & Setup

Install FaizDB via 1-line automated shell script, pre-compiled static binary, Docker Compose, or link in-process as an embedded library.

1. Automated 1-Line Standalone Install

Installs the pre-compiled native binary directly into /usr/local/bin on Linux and macOS, or user path on Windows.

# Linux & macOS (Apple Silicon / Intel x86_64)
curl -sSf https://faizdb.ict.house/install.sh | sh
# Windows PowerShell (x64)
irm https://faizdb.ict.house/install.ps1 | iex

2. Official Download Channels (v0.1.0)

All release assets include SHA256 checksum verification files.

Platform / OS Architecture Binary Target Format
Linux x86_64 x86_64-unknown-linux-musl (Zero C Libc) tar.gz
Linux (ARM64 / Graviton) aarch64 aarch64-unknown-linux-musl tar.gz
macOS (Apple Silicon) arm64 (M1/M2/M3/M4) aarch64-apple-darwin tar.gz
macOS (Intel) x86_64 x86_64-apple-darwin tar.gz
Windows x86_64 x86_64-pc-windows-msvc zip

3. Embedded SQLite-Style Mode (Zero-Dependency)

Link faizdb-core directly into your Rust, Python, or Tauri desktop app. Runs purely in-process with zero network daemons.

# Add to your Cargo.toml:
[dependencies]
faizdb-core = "0.1.0"
