FaizDB Documentation

FaizDB is an enterprise-grade, distributed, AI-native NoSQL database engine written in 100% memory-safe Rust. Fast as SQLite, flexible as MongoDB, and intelligent with native Vector & Knowledge Graph search.

🌐
4-Way Multi-Protocol Gateway
Native MongoDB Wire (27017), PostgreSQL Wire (5432), ultra-fast gRPC (50051), and REST/WS (27018) on one unified engine.
🚀
320,000+ Writes / Sec
Ultra-high throughput LSM-Tree storage with zero garbage collection lag spikes and MVCC ACID snapshot isolation.
🤖
AI-Native Vector & GraphRAG
Sub-millisecond HNSW vector matching (up to 4096 dimensions) and native multi-hop knowledge graph traversal.
🌍
Multi-Region Geo-Replication
Active-Active multi-datacenter replication with mathematically guaranteed Strong Eventual Consistency via CRDTs.

1. Direct Rust In-Process Embedded Code Example

Add faizdb-core to your Cargo.toml:

cargo.toml 
[dependencies]
faizdb-core = { git = "https://github.com/ictdothouse/faizdb.git" }

Initialize and use the storage engine in your application:

rust in-process database 
use faizdb_core::storage::engine::{StorageConfig, StorageEngine};
use std::path::PathBuf;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    // 1. Open an embedded local database folder (or in-memory)
    let config = StorageConfig {
        data_dir: PathBuf::from("./embedded_db_data"),
        memtable_size: 4 * 1024 * 1024, // 4MB RAM footprint for constrained IoT
        sync_writes: false,
        enable_wal: true, // Crash-safe WAL with CRC32 verification
    };
    
    let db = StorageEngine::open(config)?;

    // 2. Direct in-memory write (Sub-microsecond latency)
    db.put(b"sensor:device_01", b"{\"temp\": 28.5, \"status\": \"nominal\"}")?;

    // 3. Direct point lookup
    if let Some(data) = db.get(b"sensor:device_01")? {
        println!("Retrieved Data: {}", String::from_utf8(data)?);
    }

    Ok(())
}

🏛️ Architecture & Storage Engine

FaizDB utilizes a state-of-the-art Log-Structured Merge Tree (LSM-Tree) with non-blocking concurrency primitives in Rust.

Lock-Free MemTable
Crossbeam SkipList memory buffers allow concurrent multi-threaded writes at 320k+ ops/sec without mutex bottlenecks.
Sequential Write-Ahead Log (WAL)
Guarantees strict ACID durability with CRC32 integrity verification before memory acknowledge.
Zero-Allocation Chunking
Supports up to 256 MB per document using memory-mapped streaming byte slices.
Background Compaction
Multi-tiered SSTable compaction merges sorted string tables in worker threads without impacting query latency.

🌐 Raft Consensus, High Availability & Auto-Sharding

FaizDB integrates a native, high-performance Raft Distributed Consensus Engine paired with a 16,384 Virtual Hash Slot partition ring. It guarantees automatic leader election, zero-downtime failover, and linear horizontal scale-out across bare-metal servers, VMs, and Kubernetes pods.

⚡ Sub-300ms Automated Failover
When a Leader node disconnects or crashes, follower nodes detect heartbeat timeout and elect a new Leader within 150–300ms via Raft randomized term timers.
🎯 16,384 Virtual Slot Hash Ring
Keys are partitioned into 16,384 consistent hash slots using CRC32. Shards are rebalanced across joining/leaving nodes with zero downtime.

📐 The 4 Native CRDT Mathematical Models in FaizDB

1. Version Vectors (Causal Ordering)
Tracks causal event history across $N$ regional nodes without requiring globally synchronized atomic clocks (immune to NTP drift).
2. LWW-Register (Last-Write-Wins)
Field-level deterministic conflict resolution combining hybrid physical timestamps and deterministic region ID tie-breakers.
3. OR-Set (Observed-Remove Set)
Handles distributed arrays, tags, and sets. Unique element UUID tags eliminate the classic distributed delete-resurrection bug.
4. PN-Counter (Positive-Negative)
State-based distributed counters supporting commutative increments ($P$) and decrements ($N$) for live player scores, likes, and balances.

dart / flutter 
import 'dart:convert';
import 'package:http/http.dart' as http;
import 'package:web_socket_channel/web_socket_channel.dart';

class FaizDbService {
  final String baseUrl = 'http://localhost:27018/v1';

  // 1. Fetch user data
  Future<List<dynamic>> fetchUsers() async {
    final response = await http.get(Uri.parse('$baseUrl/collections/users/documents'));
    final data = jsonDecode(response.body);
    return data['data'] ?? [];
  }

  // 2. Subscribe to real-time live events (Change Streams)
  void listenToLiveUpdates(Function(dynamic) onEvent) {
    final channel = WebSocketChannel.connect(Uri.parse('ws://localhost:27018/v1/subscribe'));
    channel.stream.listen((message) {
      final change = jsonDecode(message);
      onEvent(change);
    });
  }
}
