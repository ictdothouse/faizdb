FaizDB Documentation

FaizDB is an enterprise-grade, distributed, AI-native NoSQL database engine written in 100% memory-safe Rust. Fast as SQLite, flexible as MongoDB, and intelligent with native Vector & Knowledge Graph search.

🍃
Drop-in MongoDB Wire Protocol
Connect PyMongo, Mongoose, Prisma, or PHP on Port 27017 without modifying existing application code.
🚀
320,000+ Writes / Sec
Ultra-high throughput LSM-Tree storage with zero garbage collection lag spikes.
🤖
AI-Native Vector & GraphRAG
Sub-millisecond HNSW vector matching (up to 4096 dimensions) and native multi-hop graph traversal.
🛡️
Zero-Trust Enterprise Security
Default AES-256-GCM encryption, Argon2id password hashing, and Point-In-Time Disaster Recovery (PITR).

📦 1-Line Universal Installation

Install FaizDB across any operating system using our automated one-line bootstrappers:

🐧 Linux (Ubuntu, Debian, CentOS, RHEL, Arch) & 🍎 macOS (Apple Silicon & Intel)

bash 
curl -fsSL https://raw.githubusercontent.com/ictdothouse/faizdb/main/scripts/install.sh | bash

🪟 Windows (PowerShell)

powershell 
iwr -useb https://raw.githubusercontent.com/ictdothouse/faizdb/main/scripts/install.ps1 | iex

🐳 Docker & Kubernetes

bash 
git clone https://github.com/ictdothouse/faizdb.git
cd faizdb
docker compose up -d

⚡ 60-Second Quickstart

Launch the FaizDB Dual-Protocol Daemon in one command:

bash 
# Start MongoDB Wire on 27017 and REST/WebSockets on 27018
faizdb serve --wire-port 27017 --http-port 27018

Open an interactive multi-dialect REPL shell:

bash 
faizdb shell

Inside the shell, execute queries in SQL, MongoDB Syntax, or FaizQL:

sql / mongo 
-- SQL Syntax:
INSERT INTO users {"name": "Ahmad Faiz", "role": "Architect", "score": 9800};
SELECT * FROM users WHERE score >= 9000;

-- MongoDB Syntax:
db.users.insert({"name": "Cyber Specialist", "role": "Security", "score": 9200});
db.users.find({"role": "Security"});

🍃 MongoDB Wire Protocol Integration (Port 27017)

FaizDB listens natively on standard port 27017. You can connect any existing MongoDB tool or driver directly.

Python (`pymongo`)

python 
from pymongo import MongoClient

# Drop-in connection to FaizDB (Zero Code Changes)
client = MongoClient("mongodb://127.0.0.1:27017")
db = client["enterprise_db"]
col = db["analytics"]

# Insert Document
col.insert_one({"device": "sensor-01", "temp": 36.4, "status": "nominal"})

# Query Document
record = col.find_one({"device": "sensor-01"})
print("Found Record:", record)

Node.js / TypeScript (`mongodb` / `mongoose`)

typescript 
import { MongoClient } from 'mongodb';

const client = new MongoClient('mongodb://127.0.0.1:27017');
await client.connect();
const collection = client.db('app_db').collection('users');

await collection.insertOne({ name: 'Faiz Aziz', tier: 'Enterprise', _ttl: 60 });
console.log('Saved with 60-second auto-expiry TTL!');

📊 Complex Aggregation & Analytics Pipeline Engine

FaizDB includes a full-featured in-memory Aggregation Pipeline supporting $match, $group, $project, $sort, $limit, and $skip.

python aggregation 
pipeline = [
    { "$match": { "revenue": { "$gt": 0 } } },
    { "$group": { 
        "_id": "$plan", 
        "totalRevenue": { "$sum": "$revenue" },
        "avgRevenue": { "$avg": "$revenue" },
        "customerCount": { "$sum": 1 }
    }},
    { "$sort": { "totalRevenue": -1 } }
]

results = list(col.aggregate(pipeline))
print("Financial Aggregation Report:", results)

🔍 Full-Text Search Engine (Okapi BM25 & Fuzzy Typo Tolerance)

FaizDB automatically builds an inverted index for text fields with statistical relevance scoring ($k_1=1.2, b=0.75$) and Levenshtein distance typo tolerance.

http post /v1/collections/{name}/search 
curl -X POST http://localhost:27018/v1/collections/articles/search \
  -H "Content-Type: application/json" \
  -d '{
    "query": "quantm compyter",
    "fuzzy": true,
    "top_k": 5
  }'

💾 Backup, Snapshot & Point-In-Time Disaster Recovery (PITR)

Generate non-blocking online snapshots with cryptographic checksum integrity verification:

bash cli 
# Create Atomic Consistent Snapshot:
faizdb backup --output ./backups/faizdb_snapshot_2026.json

# Restore Database Instantaneously:
faizdb restore --input ./backups/faizdb_snapshot_2026.json
