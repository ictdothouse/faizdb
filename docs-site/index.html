FaizDB Documentation

FaizDB is an enterprise-grade, distributed, AI-native NoSQL database engine written in 100% memory-safe Rust. Fast as SQLite, flexible as MongoDB, and intelligent with native Vector & Knowledge Graph search.

🍃
Drop-in MongoDB Wire Protocol
Connect PyMongo, Mongoose, Prisma, or PHP on Port 27017 without modifying existing application code.
🚀
320,000+ Writes / Sec
Ultra-high throughput LSM-Tree storage with zero garbage collection lag spikes.
🤖
AI-Native Vector & GraphRAG
Sub-millisecond HNSW vector matching (up to 4096 dimensions) and native multi-hop graph traversal.
🛡️
Zero-Trust Enterprise Security
Default AES-256-GCM encryption, Argon2id password hashing, and Point-In-Time Disaster Recovery (PITR).

💎 Why FaizDB Beats Incumbent Databases

Traditional stacks force developers to manage 4 to 5 separate database servers (Postgres + Redis + MongoDB + Elasticsearch + Pinecone). FaizDB unifies them all into one ultra-compact, high-performance binary.

🛡️ Zero-Trust Security Suite

FaizDB implements a comprehensive, defense-in-depth security model engineered for enterprise compliance (SOC2, HIPAA, ISO 27001, GDPR).

🔒 AES-256-GCM AEAD Encryption
Authenticated Encryption with Associated Data ensures ciphertext integrity and prevents bit-flipping attacks on disk and backup archives.
🔑 Argon2id Password Hashing
State-of-the-art memory-hard key derivation function ($m=65536, t=3, p=4$) that resists GPU/ASIC brute-force cracking.
👥 Granular RBAC & JWT Tokens
Three discrete permission tiers: Admin (full cluster & audit control), ReadWrite (CRUD operations), and ReadOnly (analytics queries).
📝 Immutable Security Audit Logs
Every administrative action, failed authentication, and data mutation is permanently recorded in structured audit logs with IP, timestamp, and request ID.

⚡ 60-Second Quickstart

Launch the FaizDB Dual-Protocol Daemon in one command:

bash 
# Start MongoDB Wire on 27017 and REST/WebSockets on 27018
faizdb serve --wire-port 27017 --http-port 27018

Open an interactive multi-dialect REPL shell:

bash 
faizdb shell

Inside the shell, execute queries in SQL, MongoDB Syntax, or FaizQL:

sql / mongo 
-- SQL Syntax:
INSERT INTO users {"name": "Ahmad Faiz", "role": "Architect", "score": 9800};
SELECT * FROM users WHERE score >= 9000;

-- MongoDB Syntax:
db.users.insert({"name": "Cyber Specialist", "role": "Security", "score": 9200});
db.users.find({"role": "Security"});

🍃 MongoDB Wire Protocol Integration (Port 27017)

FaizDB listens natively on standard port 27017. You can connect any existing MongoDB tool or driver directly.

Python (`pymongo`)

python 
from pymongo import MongoClient

# Drop-in connection to FaizDB (Zero Code Changes)
client = MongoClient("mongodb://127.0.0.1:27017")
db = client["enterprise_db"]
col = db["analytics"]

# Insert Document
col.insert_one({"device": "sensor-01", "temp": 36.4, "status": "nominal"})

# Query Document
record = col.find_one({"device": "sensor-01"})
print("Found Record:", record)

Node.js / TypeScript (`mongodb` / `mongoose`)

typescript 
import { MongoClient } from 'mongodb';

const client = new MongoClient('mongodb://127.0.0.1:27017');
await client.connect();
const collection = client.db('app_db').collection('users');

await collection.insertOne({ name: 'Faiz Aziz', tier: 'Enterprise', _ttl: 60 });

🏛️ Architecture & Storage Engine

FaizDB utilizes a state-of-the-art Log-Structured Merge Tree (LSM-Tree) with non-blocking concurrency primitives in Rust.

Lock-Free MemTable
Crossbeam SkipList memory buffers allow concurrent multi-threaded writes at 320k+ ops/sec without mutex bottlenecks.
Sequential Write-Ahead Log (WAL)
Guarantees strict ACID durability with CRC32 integrity verification before memory acknowledge.
Zero-Allocation Chunking
Supports up to 256 MB per document using memory-mapped streaming byte slices.
Background Compaction
Multi-tiered SSTable compaction merges sorted string tables in worker threads without impacting query latency.

🌐 HTTP REST API Reference (Port 27018)

Connect any HTTP-capable client, serverless function, or webhook directly to FaizDB:

Method Endpoint Description
GET /v1/health Server health check and version telemetry
GET /v1/info Engine capabilities and feature manifest
POST /v1/query Execute SQL, MongoDB JSON or FaizQL raw string
GET /v1/collections/{name}/documents Retrieve all documents in collection
POST /v1/collections/{name}/documents Insert new JSON document (with optional _ttl)
DELETE /v1/collections/{name}/documents/{id} Delete document by unique ID
POST /v1/collections/{name}/aggregate Execute complex aggregation pipeline stage array

🌐 Raft Consensus, High Availability & Auto-Sharding

FaizDB includes a native Raft distributed consensus implementation with automated leader election and 16,384 virtual hash slots:

Automated Failover
When a leader node goes offline, followers initiate a Term Election and elect a new Leader within 150-300ms.
Consistent Hash Ring
Keys are partitioned into 16,384 virtual slots using CRC32 hash algorithms for balanced distribution.

🔵 Go Official SDK Integration Guide

Connect using the official type-safe Go SDK (github.com/ictdothouse/faizdb/bindings/go):

go 
package main

import (
	"fmt"
	"github.com/ictdothouse/faizdb/bindings/go"
)

func main() {
	client := faizdb.NewClient("http://localhost:27018")
	_, err := client.Login("admin", "faizdb-admin-2026")
	if err != nil {
		panic(err)
	}

	users := client.Collection("users")
	docID, err := users.Insert(map[string]interface{}{
		"name":  "Ahmad Faiz",
		"email": "faiz@ict.house",
		"role":  "Architect",
	})
	if err != nil {
		panic(err)
	}
	fmt.Printf("Document inserted with ID: %s\n", docID)
}
